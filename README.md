# Family Meals

A [Chickadee Bandit](https://chickadeebandit.com/app-library/family-meals) app.

Plan the week's meals day by day. Pick from your recipe book, assign who's cooking, and add ingredients directly to your grocery list.

## Features

- Day-by-day plan for the week.
- Pick meals from the household's Recipes app.
- Assign who is cooking each night.
- Send the week's ingredients to the shared Grocery List.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-family-meals/releases/latest/download/bundle.json
```
